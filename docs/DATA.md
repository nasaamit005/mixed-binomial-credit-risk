# Data guide

| Source | Use | Access | Redistribution |
|---|---|---|---|
| Synthetic (seeded, `SEED = 20261101`) | exact engine, 1/n correction, t-copula, IS, tests | generated by code | free to publish |
| Federal Reserve charge-off / delinquency rates (FRED: CORALACBS, CORBLACBS, CORCREXFACBS, CORCCACBS, DRBLACBN) | proxy calibration of the systematic-factor variance across credit cycles | `python scripts/fetch_fred.py` (no API key) | public series; cite FRED |
| Freddie Mac Single-Family Loan-Level Dataset (Release 47, July 2026) | real portfolios of any n, vintage default rates, loss severities (LGD) | free registration at Freddie Mac Clarity | **do not redistribute** raw or derived loan-level data without a licence from Freddie Mac |
| S&P / Moody's / Fitch default studies | PD-by-rating and yearly default rates | published summary tables only | proprietary: cite, do not copy tables wholesale |
| BIS Basel framework text | IRB constants | bis.org | public |

## Rules enforced in this repo
1. `data/raw/` is git-ignored. Nothing downloaded is ever committed.
2. `data/derived/` holds only synthetic outputs and, if licence permits, small aggregates.
3. FRED series are **loss-rate proxies**, not default counts. `rates_to_pseudo_counts` needs an
   assumed effective portfolio size `n_eff`; results MUST be reported as a sensitivity over n_eff.
4. Before publishing any table derived from Freddie Mac data, re-read its current terms.

## Freddie Mac workflow (manual download, then processing)
1. Register at Freddie Mac Clarity and download the Standard Dataset vintage files to `data/raw/freddie/`.
2. Build annual default indicators per vintage (e.g. 90+ days delinquent within 12 months of observation).
3. Sample n loans per vintage-year to build portfolios of controlled size; feed yearly default counts
   to `mbcr.calibration.fit_mle` / `fit_bayes`.
4. Use the loss fields to fit a Beta LGD (mean, sd) for `simulate_losses(lgd_model="beta")`.
