Mixed-binomial credit risk

1. The exact loss distribution

Each curve is the exact mixed-binomial density (no simulation noise) for a portfolio of n loans. The dashed black curve is the Vasicek large-portfolio limit. Small portfolios put more probability in the right tail than the limit predicts. Vertical dotted lines mark each portfolio’s 99.9% VaR. The red curve is a t-copula portfolio (ν = 5, n = 100) with heavier joint tails.

2. Where the large-portfolio approximation fails

Relative error of the Vasicek VaR over portfolio size (columns) and asset correlation (rows). Hover a cell for the exact value. Red means the limit understates risk.

3. Convergence order

Both axes are logarithmic. The plain limit’s error falls like 1/n. Adding the closed-form 1/n granularity term gains a full order, so the residual falls like 1/n².

4. Tail dependence (t-copula)

Same PD and correlation, but heavier joint tails: the infinite-portfolio VaR rises sharply as the degrees of freedom ν fall. Copula choice is a bigger source of model risk than finite size once n ≥ 250.

5. Capital impact

Unexpected-loss capital for a finite portfolio against the Vasicek-limit capital that large-portfolio formulas such as Basel IRB assume. Hover a bar for the gap.

Read with care. The 1/n expansion is the established granularity-adjustment framework, not a new theorem. It is asymptotic and unreliable for very small, low-PD portfolios (worst case: a 41% residual at n = 25, PD 0.1%). The capital figures use the Vasicek ρ directly, not the Basel IRB-prescribed ρ(PD), and the IRB constants must be verified against the BIS text before any publication use.
